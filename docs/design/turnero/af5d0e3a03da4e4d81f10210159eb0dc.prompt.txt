Pantalla pública para que un paciente odontológico reserve un turno online, sin login. Marca OdontoGrid, estética clínica, limpia y cálida, en español rioplatense, responsive (desktop y mobile). Encabezado con el nombre del consultorio 'Consultorio Demo' y el subtítulo 'Reservá tu turno online'. Panel de filtros: selector de Profesional, selector de Prestación y navegación de semana con flechas y rango de fechas. Grilla de horarios disponibles agrupada por día (lunes a domingo), con botones tipo chip para cada horario libre (ej. 09:00, 09:30, 10:00). Al elegir un horario, mostrar un formulario de reserva en tarjeta: Nombre y apellido, Teléfono, resumen del turno (profesional, prestación, fecha y hora) y botón primario 'Confirmar reserva'. Debajo, una tarjeta de confirmación con código de 12 caracteres destacado, mensaje 'Guardá este código para consultar, cancelar o reprogramar tu turno' y botón 'Copiar código'. Incluir un enlace secundario 'Ya tengo un turno: consultar con mi código'. Usar solo datos ficticios de ejemplo. No usar datos reales de pacientes. Estilo: teal #0D9488 como acento primario, fondos blancos y slate suave, bordes finos, radios de 8px, tipografía Plus Jakarta Sans para títulos e Inter para cuerpo.
